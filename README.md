# Startup Stack — Orkestrasi Layanan Harian

> Satu skrip batch yang menyalakan seluruh tumpukan layanan harian dalam satu jendela Windows Terminal dengan lima tab.

## ✨ Fitur

- 5 layanan paralel
- 1 jendela, 5 tab
- Start-up otomatis

## 🛠 Tech Stack

"Windows Batch" "Windows Terminal"

## 🚀 Menjalankan

```
startup.cmd
```

## 📌 Catatan

Proyek ini merupakan bagian dari portofolio pribadi. Kode disusun untuk kebutuhan nyata,
bukan sekadar demo, sehingga sebagian konfigurasi spesifik lingkungan mungkin perlu
disesuaikan sebelum dijalankan.
